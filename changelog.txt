- Structure-based trees now grow centred on the saplings instead of offset from them.


26.1.2-1.2.0

- Added a "minimal" mode (startup config option, off by default) that skips registering the decorative and functional wood blocks - stairs, slabs, fences, fence gates, pressure plates, buttons, doors, trapdoors, bookshelves and signs - for every tree. Logs, wood, planks, leaves, saplings and fruit are always kept. This roughly halves the number of block states the mod adds, lowering RAM usage. It must be set to the same value on the server and every client, as it changes which blocks exist.
